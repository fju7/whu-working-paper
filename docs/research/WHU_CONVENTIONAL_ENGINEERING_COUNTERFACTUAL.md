# Conventional engineering counterfactual

A competent conventional software/research engineering team would likely reduce the demonstrated fatal
failure rate substantially. RLS/grants, durable serialization, explicit state machines, capability
transitions, schema-generated validators, integration tests, scoring contracts and production-readiness
gates are ordinary engineering responsibilities. Independent human design/review would also avoid using
the same agent as architect, implementer, evaluator and acceptance adjudicator.

Hard problems would remain: defining a qualified reference without treating it as omniscient truth;
family/report equivalence; access/version truth; pivotal/consequential labels; open-world stopping;
counterevidence; and domain-dependent evidence classes. Those are research semantics, not eliminated by
better software.

The evidence therefore does not show “WHU is impossible.” It shows WHU is not reliably buildable or
operable when current LLM agents hold holistic workflow-design, implementation and self-certification
authority. Strong human/deterministic engineering might expose whether acquisition and reference costs
remain viable, but that counterfactual has not been measured.
